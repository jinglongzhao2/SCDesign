# Synthetic Control Design

This is a list of all provided materials' names and usages. All the running times are reported using a personal laptop with the following specifications:

    Operating System: Windows 11 Enterprise version 23H2
    Processor: Intel(R) Core(TM) Ultra 5 135H   3.60 GHz
    RAM: 16.0 GB (15.6 GB usable)
    System type: 64-bit operating system, x64-based processor 

Some simulation files were designed to be run on an online computing cluster with 1000 random seeds. For a local test run, the random seed can be fixed manually as described below.

## Structure of the Replication Package

The replication package is organized as follows:

```text
SyntheticControlDesign/
    README.md

    Single Simulation (generates Figures 4, 5, OA5, OA6, OA7, OA8)/
        SCdesign_LazyRun.R

    Many Simulations (generates Tables 2, 3, OA1, OA2, OA3, OA4, OA5, OA6)/
        Main_LazyRun.R
        Analyzing_Outputs.R
        Main_Nonlinear_LazyRun.R
        Analyzing_Outputs_Nonlinear.R

        output/
        output_nonlinear/

    Walmart Data Simulations (generates Table 1, Figures 2, 3, OA1, OA2, OA3, OA4)/
        Walmart.csv
        Walmart_LazyRun.R
        Walmart_Randomization.R
        Analyzing_Outputs_Walmart.R

        output/
        output_Randomization/

    Additional Many Simulations (generates Tables OA7, OA8)/
        Main_LazyRun.R
        Analyzing_Outputs.R

        output/
```

The three main folders generates different tables and figures of the paper.

## Folder 1: `Single Simulation (generates Figures 4, 5, OA5, OA6, OA7, OA8)/`

This folder contains code for generating the simulation figures: Figures 4, 5, OA5, OA6, OA7, OA8.

### `SCdesign_LazyRun.R`

- **Purpose:** Generates one simulation environment as described in Section 5.1.
- **How to run:** In Line 7, specify one of the following values:
  - `input.variance = 1`, reproduces Figures 4 and 5.
  - `input.variance = 5`, reproduces Figures OA5 and OA6.
  - `input.variance = 10`, reproduces Figures OA7 and OA8.
- **Running time:** Less than 1.5 hours for each value of `noise.variance`.
- **Output files:**
  - `ObservedData_NoiseVariance=1.png` → Figure 4
  - `Residuals_NoiseVariance=1.png` → Figure 5
  - `ObservedData_NoiseVariance=5.png` → Figure OA5
  - `Residuals_NoiseVariance=5.png` → Figure OA6
  - `ObservedData_NoiseVariance=10.png` → Figure OA7
  - `Residuals_NoiseVariance=10.png` → Figure OA8

## Folder 2: `Many Simulations (generates Tables 2, 3, OA1, OA2, OA3, OA4, OA5, OA6)/`

This folder contains code for the simulation studies used to generate Tables 2, 3, OA1, OA2, OA3, OA4, OA5, OA6.

### `Main_LazyRun.R`

- **Purpose:** There are two tasks. Task 1: compare different formulations of synthetic control designs across many simulations. Task 2: compare the synthetic control design (implemented using the constrained formulation) with randomization methods. 
- **Cluster run:** This file is designed to be run on an online computing cluster with 1000 random seeds. The random seed is set in Line 37 by
  ```r
  repetition.RANDOM.SEED = as.numeric(Sys.getenv("SGE_TASK_ID"))
  ```
- **Local test run:** To run a local test, comment out Line 37 and instead set the following as in Line 36
  ```r
  repetition.RANDOM.SEED = 123456
  ```
- **Running time:** Less than 24 hours for each seed.
- **Intermediate output folder:** `output/`
- **Intermediate output files:** For each random seed, for example `repetition.RANDOM.SEED = 123456`, the script produces:
  - `123456Different_Formulations_ATE.txt` — used in Task 1
  - `123456Different_Formulations_ATE_null_hypothesis.txt` — used in Task 1
  - `123456Different_Formulations_ATEC.txt` — sanity check only
  - `123456Different_Formulations_ATET.txt` — used in Task 1
  - `123456Different_Formulations_ControlWeights.txt` — sanity check only
  - `123456Different_Formulations_TreatmentWeights.txt` — sanity check only
  - `123456RandomAssignment_RA1NN.txt` — used in Task 2
  - `123456RandomAssignment_RA5NN.txt` — used in Task 2
  - `123456RandomAssignment_RADiM.txt` — used in Task 2
  - `123456RandomAssignment_RARegAdj.txt` — used in Task 2
  - `123456StratifiedAssignment_StADiM.txt` — used in Task 2

### `Analyzing_Outputs.R`

- **Purpose:** Combines the intermediate files generated by running `Main_LazyRun.R` with 1000 random seeds.
- **Input folder:** `output/`
- **Expected input:** After 1000 runs, the `output/` folder should contain 11000 intermediate files.
- **Running time:** Less than 1 minute.
- **Output files:** If today is "DATE", the script produces:
  - `"DATE"Average_Different_Optimization_Methods_ATE_ConsUncons.txt` → Table 2
  - `"DATE"Compare_With_Randomization.txt` → Table 3
  - `"DATE"Average_Different_Optimization_Methods_ATE_Others.txt` → Table OA1
  - `"DATE"Average_Different_Optimization_Methods_ATET.txt` → Table OA2
  - `"DATE"Average_Different_Optimization_Methods_ATE_null_hypothesis.txt` → Table OA3

## Suggested Order for Replication

To reproduce the results, run the scripts in the following order.

### A. Simulation figures

1. Go to `Figure 4-5, Figure OA5-OA8/`.
2. Run `SCdesign_LazyRun.R` three times, setting `noise.variance` equal to `1`, `5`, and `10`.

### B. Main simulation tables

1. Go to `Table 2-5, Table OA1-2/`.
2. Run `Different_optimization_methods.R` for random seeds 1 through 1000.
3. Run `Analyzing_Outputs.R`.
4. Run `Nonlinear2.R` for random seeds 1 through 1000.
5. Run `Analyzing_Outputs_Nonlinear2.R`.
6. Run `RandomAssignment.R` for random seeds 1 through 1000.
7. Run `Analyzing_Outputs_RandomAssignment.R`.

### C. Walmart application

1. Go to `Figure 2-3, OA1-4, Table 1/`.
2. Run `Walmart_LazyRun.R`.
3. Run `Walmart_Randomization.R` for random seeds 1 through 1000.
4. Run `Analyzing_Outputs_RandomAssignment.R`.

## Notes on Output Files

Some output file names begin with `"DATE"`. This indicates that the actual file name includes the date on which the script was run.

Some scripts generate additional sanity-check output files that are not directly reported in the paper. These files are retained to help verify the computations.
